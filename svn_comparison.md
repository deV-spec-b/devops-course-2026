\# Git и SVN



1\. Почему в Git ветвление дешёвое, а в SVN дорогое?

В Git ветка — это указатель на коммит. Она создаётся сразу и почти не занимает места. В SVN ветка — копия каталога на центральном сервере, поэтому создание медленнее и занимает место.



2\. Можно ли в SVN сделать коммит без интернета?

Нет. Коммит в SVN сразу записывается на центральный сервер, без сети его нет. В Git коммит сначала локальный, интернет нужен только для push.



3\. В каких случаях SVN ещё может быть предпочтительнее?

В старых банковских и корпоративных системах, где репозиторий уже на SVN, нужны права на отдельные каталоги и частичное скачивание большого монорепозитория. Новые проекты обычно начинают на Git.
