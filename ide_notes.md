\# Git в VS Code и в терминале



Удобно в VS Code:

1\. Diff файла виден до коммита: зелёные и красные строки.

2\. История коммитов показана графически, без git log.

3\. GitLens пишет над строкой, кто и когда её менял.



Удобнее в терминале:

1\. Точные команды branch, push и log: на сервере будет только терминал, без кнопок VS Code.
